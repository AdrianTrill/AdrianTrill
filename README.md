# Hi 👋, I'm Adrian

![Profile Views](https://komarev.com/ghpvc/?username=AdrianTrill&color=blue)

## 🚀 About Me
I'm a software engineer on the AI team at **Computacenter** in Cluj-Napoca, Romania. I have a Computer Science degree from [Babeș-Bolyai University](https://www.ubbcluj.ro/) and I'm now doing a Master's in Artificial Intelligence there.

I build LLM agents, RAG pipelines, and the backend and infrastructure around them. Most of my work is about making AI reliable, which means grounding answers in real data, measuring quality properly, and keeping a human in the loop for decisions that matter.

Outside of coding, I enjoy **hitting the gym 🏋️ and riding motorcycles 🏍️**.

## 🧠 What I Work On
- **AI Data Factory (with NVIDIA)**: I lead a multi-agent platform where a supervisor coordinates 11 specialist agents to turn natural-language requests into governed, reusable data products. Built on NVIDIA NIM, NeMo Agent Toolkit, Milvus, and Kubernetes.
- **AGSM**: I lead an AIOps platform where 18 agents investigate infrastructure and security incidents, with every LLM finding checked against the database and NVIDIA NeMo Guardrails on every model call.
- **OrchestraIQ**: GPU-accelerated technician scheduling with NVIDIA cuOpt, plus an LLM assistant for planners.
- **Multimodal RAG**: a survey assistant for a retail client covering 30+ stores and 6,500+ photos, with hybrid search, reranking, and text-to-SQL.

_These are company projects, so the code is private._
