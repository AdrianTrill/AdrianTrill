## 🚀 About Me

I'm a software engineer on the AI team at **Computacenter** in Cluj-Napoca, Romania 🇷🇴. I have a Computer Science degree from [Babeș-Bolyai University](https://www.ubbcluj.ro/) and I'm now doing a Master's in Artificial Intelligence there.

I build LLM agents, RAG pipelines, and the backend and infrastructure around them. Most of my work is about making AI reliable, which means grounding answers in real data, measuring quality properly, and keeping a human in the loop for decisions that matter.

- 🔭 Leading the **AI Data Factory** (with NVIDIA) and **AGSM** at Computacenter
- 🎓 Master's in Artificial Intelligence (AI4CI) at Babeș-Bolyai University
- 🏋️ Outside of coding: the gym and riding motorcycles 🏍️

## 🧠 What I Work On

| Project | What it does | Built with |
|---|---|---|
| **AI Data Factory** (with NVIDIA) | Multi-agent platform where a supervisor coordinates 11 specialist agents to turn natural-language requests into governed, reusable data products | NVIDIA NIM, NeMo Agent Toolkit, Milvus, Kubernetes |
| **AGSM** | AIOps platform where 18 agents investigate infrastructure and security incidents, with every LLM finding verified against the database | FastAPI, Next.js, PostgreSQL, Redis, NeMo Guardrails |
| **OrchestraIQ** | GPU-accelerated technician scheduling for hardware integration centers, with an LLM assistant for planners | NVIDIA cuOpt, OR-Tools, FastAPI, Next.js |
| **Survey Intelligence** | Multimodal RAG over site surveys from 30+ stores and 6,500+ photos for a retail client | OpenAI, ChromaDB, BM25, CLIP |

<sub>These are company projects, so the code is private.</sub>
